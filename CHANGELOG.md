## [0.1.0]

### Added

- OpenAI-compatible chat-completion routing.
- Model aliases for self-hosted LLM runtimes.
- Ollama, llama.cpp and vLLM backend support.
- Priority and least-inflight route selection.
- Backend-wide concurrency limits.
- Health-aware routing and readiness.
- Bounded pre-response failover.
- Incremental SSE streaming.
- Optional bearer authentication.
- Separate backend credentials.
- Prometheus metrics.
- Docker and local Ollama demo.
